Key Architectural Decisions

Layered Monolith Constraint
No controller may touch database tables directly, only repository classes are allowed to handle queries, and all business rules reside inside transactional service components.
Handwritten Mappers over Generated Libraries
Avoid compiler overhead or annotation processors, utilize simple utility final classes with private constructors for explicit, error free entity transformations.
Strict Parameter Validation Exception Mapping
Method parameter constraints throw a HandlerMethodValidationException which the GlobalExceptionHandler maps directly to standardized RFC 9457 Problem JSON responses carrying accurate error keys.
